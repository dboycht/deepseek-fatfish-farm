# 贴纸包与「缺表情」系统

内置只有 12 个基础表情（代码绘制）。真正好用的是**用户贴纸包**：
用 GPT 批量画一批 512×512 透明表情，打包导入，之后模型就能在聊天里用它们。

## 它怎么工作

1. 模型在回复里写 `[[sticker:<id>]]` 使用一个贴纸；
2. 如果它写了一个**不存在**的 id，或者明确写 `[[sticker:need:委屈]]`，
   软件会把这句「缺什么」记下来（带出现次数和上下文）；
3. 聊天输入框 → 🐟 面板里能看到缺的表情，点「导出需求清单（含 GPT 提示词）」；
4. 把导出的 Markdown 丢给 GPT 批量生成 → 得到 zip → 「导入 zip」；
5. 重新打开面板就能看到新贴纸，模型下一轮也能用（提示词里会列出可用 id）。

### 模型实际可以怎么写

模型经常不按标准格式写，所以解析器同时接受：

| 写法 | 结果 |
| --- | --- |
| `[[sticker:shy]]` / `[sticker:shy]` | 使用贴纸 |
| `[贴纸:shy]` / `【贴纸：shy】` | 使用贴纸（中文别名、全角冒号） |
| `[表情:shy]` / `[表情包:shy]` | 使用贴纸 |
| `[[fish:shy]]` | 兼容旧写法 |
| `[贴纸:need:委屈]` / `[表情包:需要:委屈]` | 记入缺表情 |
| `[贴纸:委屈]`（id 不存在） | 记入缺表情 |

> 注意：像 `[贴纸:shy]` 里的 `shy` 是内置表情，**不会**进需求清单——
> 它只是被当成普通文字显示，缺失记录只针对「不存在的 id」。
> 中文指令是在 2026-10-22 的修复里补上的。

## 文件位置

```
<配置目录>/stickers/
├── <packId>/
│   ├── manifest.json
│   ├── pout.png
│   └── ...
└── wishes.json        # 缺表情记录
```

- 配置目录见「设置 → 数据」；也支持 `FATFISH_HOME` 整体搬走。
- 贴纸图片通过 `fatfish-sticker://<packId>/<file>` 只读提供，路径穿越会被拒绝。

## 目录与 manifest

```text
my-sticker-pack/
├── manifest.json
├── pout.png
├── surprised.png
└── sleepy2.png
```

```json
{
  "id": "my-sticker-pack",
  "name": "我的大肥鱼补充表情",
  "version": "1.0.0",
  "author": "your-name",
  "license": "CC-BY-NC-4.0",
  "description": "用 GPT 批量生成的补充表情",
  "items": [
    { "id": "pout", "label": "鼓嘴", "file": "pout.png", "tags": ["生气", "撒娇"] },
    { "id": "surprised", "label": "震惊", "file": "surprised.png", "tags": ["惊讶"] }
  ]
}
```

| 字段 | 规则 |
| --- | --- |
| `id`（包） | 2~32 位小写字母/数字/短横线，不能与已安装包重复 |
| `name` / `version` | 必填（version 缺省 1.0.0） |
| `items` | 1~200 个；每项 `id` 全局唯一，不能与内置/其它包冲突 |
| `items[].file` | 相对路径，png/webp/gif/jpg，不能 `..` 或绝对路径 |
| 图片 | 建议 512×512 透明 PNG、≤4MB；导入时会检查能否解码、至少 64px |

## 图片规范（给 GPT）

- Q 版鲸鱼娘：深蓝到浅蓝渐变长发、呆毛、白色女仆发带、蓝眼、白围裙（蓝色小鲸鱼）、蓝鲸尾；
- 512×512，透明背景，角色居中，粗描边、干净赛璐璐上色；
- 表情夸张但可爱，不要文字/水印/多余角色/复杂背景；
- 同一套保持完全一致的角色特征；
- 不要模仿具体画师或作品；角色是社区二创，仅非商业同人使用。

## 操作路径

| 操作 | 位置 |
| --- | --- |
| 看缺什么 / 导入 / 导出需求 | 聊天输入框 → 🐟 |
| 打开贴纸目录 | 🐟 面板 → 打开目录 |
| 删除贴纸包 | 🐟 面板 → 对应包 → 删除 |
| 清空缺表情记录 | 🐟 面板 → 清空记录 |

## 校验与常见错误

导入时会依次检查：manifest 字段、包 id/贴纸 id 冲突、文件是否存在、体积、能否解码、尺寸、是否接近正方形。

| 报错 | 原因 |
| --- | --- |
| `manifest 校验失败：…` | id/文件名/字段不合规，按提示改 |
| `贴纸 id「joy」与内置或其它贴纸包冲突` | 换一个 id（内置 12 个：joy/hungry/rice/sleepy/proud/shy/angry/cry/work/love/dizzy/smug） |
| `缺少文件：pout.png` | manifest 里写了但 zip 里没有 |
| `无法解码` | 图片损坏或不是真正的图片 |
| `已存在同名贴纸包` | 先删除旧包再导入 |
| `zip 里没有 manifest.json` | 把 manifest 放在 zip 根目录或单一文件夹里 |
